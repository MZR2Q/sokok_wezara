# نظام متابعة الصكوك (نموذج أولي)

نموذج أولي (Prototype) بواجهة عربية (RTL) لنظام **متابعة توثيق صكوك المساجد** على مستوى المركز الرئيسي والفروع والموظفين — بهوية بصرية مستوحاة من وزارة الشؤون الإسلامية والدعوة والإرشاد.

> ⚠️ هذا نموذج توضيحي للفكرة فقط. جميع البيانات **تجريبية** وتُولَّد وتُحفظ محلياً في متصفحك (`localStorage`)، ولا يوجد خادم أو قاعدة بيانات حقيقية.

## الفكرة
كثير من المساجد صكوكها غير موثّقة. النظام يتيح:

1. **المركز الرئيسي (الوزارة):** إسناد دفعات صكوك جديدة للفروع، ومتابعة أداء كل الفروع (إجمالي / منتهٍ / جارٍ / خامل)، والدخول على أي فرع لرؤية توزيع صكوكه على الموظفين.
2. **الفرع (16 فرعاً):** استقبال الصكوك المسندة إليه وتوزيعها على موظفي التوثيق (إفرادياً أو دفعة واحدة).
3. **الموظف:** تنفيذ **مسار عمل (Workflow)** محدد لكل صك، خطوة بخطوة، حتى إرفاق الصك النهائي.

### مسار عمل الصك
`استلام الصك ← مراجعة بيانات الجهة ← تدقيق الوثائق ← المراجعة الفنية بالفرع ← مراجعة الوزارة ← اعتماد وتأكيد الصك ← إرفاق الصك النهائي`

### حالات الصك
- **منتهٍ**: اكتملت جميع مراحل المسار.
- **جارٍ العمل**: بدأ العمل ولم يكتمل.
- **خامل**: مُسند لموظف لكنه لم يتحرك بعد.
- **غير موزّع**: مُسند للفرع ولم يُوزّع على موظف.

## طريقة التشغيل
لا يحتاج أي بناء أو تثبيت. افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

من صفحة الدخول اختر الصلاحية (المركز الرئيسي / فرع / موظف) لتجربة كل لوحة.

> لإعادة توليد البيانات التجريبية: افتح أدوات المطوّر ونفّذ `Store.reset()` أو امسح `localStorage`.

```
sokok_wezara/
├── index.html            # صفحة الدخول واختيار الدور
├── hq.html               # لوحة المركز الرئيسي
├── branch.html           # لوحة الفرع
├── employee.html         # لوحة الموظف (مسار العمل)
├── README.md
└── assets/
    ├── img/logo.svg      # الشعار (هوية بصرية)
    ├── css/
    │   ├── base.css        # المتغيرات، الطباعة، الهوية
    │   ├── layout.css      # الترويسة، القائمة الجانبية، الشبكات
    │   └── components.css  # البطاقات، الجداول، الشارات، المخططات، المسار، النوافذ
    └── js/
        ├── data.js         # توليد البيانات التجريبية (ببذرة ثابتة)
        ├── store.js        # طبقة الحالة والاستعلامات والحفظ
        ├── utils.js        # دوال مساعدة عامة
        ├── login.js        # منطق تسجيل الدخول
        ├── hq.js           # منطق المركز الرئيسي
        ├── branch.js       # منطق الفرع
        └── employee.js     # منطق الموظف ومسار العمل
```
